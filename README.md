Chocolate Company Sales Dashboard 

This project is a Sales Analytics Dashboard built in Power BI for a chocolate company. The goal was to analyze sales performance, profitability, shipment trends, and regional contribution using interactive visuals.

The dashboard focuses on turning raw data into meaningful business insights to support decision-making.

Key Metrics

Total Sales: $46M

Total Profit: $27M

Total Cost: $19M

Total Boxes Sold: 3M

Total Shipments: 9K

Overall Profit Margin: 57.7%

Features

KPI cards for Sales, Profit, Cost, Shipments, and Boxes

Month-over-Month growth analysis

Boxes Sold trend analysis

Shipment analysis

Country-wise sales distribution

Salesperson and Product performance using bookmarks

Profit %, LBS %, and performance indicators

Dynamic chart titles using DAX

Tools Used

Power BI

DAX

Data Modeling

Field Parameters

Bookmarks

What I Learned

This project helped me improve my skills in KPI design, DAX calculations, interactive reporting, and business-focused dashboard development.

It strengthened my ability to think beyond visuals and build dashboards that support real business decisions.
